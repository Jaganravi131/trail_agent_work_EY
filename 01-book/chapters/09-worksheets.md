## 9.2 Daily log — 2 minutes per day

Copy one row per 24 hours (not per night — the 24-hour total is the number that matters).

| Date | Start/End | Core sleep (h) | Naps (h) | **Total /24h** | Caffeine (mg) | Last caffeine time | Anchor meal Y/N + protein g | Onset (min) | 06:00 energy 1–5 | Mood 1–5 | Notes |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | |

**Two rules for the log.** Never fill it in at the end of the week; the memory is fiction. And never use it to judge yourself — it's a sensor, not an exam. If a cell is unknown, leave it blank rather than estimating; three blank cells in a row is itself a finding.

## 9.4 Shift-bag inventory

Pack at 18:35, once a week, not at 06:40.

- [ ] Snacks for tiers A1–A3 (double, in case a break evaporates)
- [ ] Filled bottle
- [ ] Sunglasses
- [ ] Eye mask + earplugs (spare pair in the bag, they always get lost)
- [ ] Change of socks — cold, dry feet measurably improve day-sleep onset for a lot of people
- [ ] Any medication you take before sleep *only if a clinician said to* (and never a new one you read about online)
- [ ] A small book or nothing. Not a feed.

## 9.5 Bedroom audit

Score each 0–2. Under 10 and your bedroom, not your schedule, is your bottleneck.

| Item | 0 | 1 | 2 |
|---|---|---|---|
| Blackout | visible gaps | dim | can't see the wall |
| Noise floor | street audible | fan/earplugs present, unused | consistently masked |
| Temperature | >22 °C | 20–22 | 18–20 |
| Phone | in hand | face down on bedside | out of the room |
| Clock visible | yes | hidden | covered/removed |
| Household knows window | no | verbally | written on fridge |
| Bed = sleep only | working/scrolling in bed | mostly | always |

## 9.7 Roster request — pre-send checklist

- [ ] Written, so there's a record
- [ ] Names the specific change (pattern, not feeling)
- [ ] Says what it costs the rota — ideally "nothing," with what you'll take on
- [ ] Includes a smaller fallback version
- [ ] Uses safety framing, not complaint framing
- [ ] Mentions the pattern of benefit to them (absence, swap requests, handover quality)
- [ ] Sent to the person who can actually say yes, cc'd to your line manager
- [ ] You have written down the answer, whatever it is, and the reason
